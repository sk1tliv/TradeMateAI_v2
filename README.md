# TradeMateAI

**TradeMate**, finansal veriler ve analizlere dayalı bir yatırım platformudur. Kullanıcılar döviz ve kripto para piyasaları hakkında bilgi alabilir, güvenli yatırım kararları verebilir ve finansal planlama hizmetlerine erişebilirler.

## Özellikler

**Piyasa Verileri:** EUR/TRY, USD/TRY ve XAU/TRY gibi popüler döviz çiftleri için gerçek zamanlı piyasa verileri sunar.

**Kripto Para Bilgisi:** Binance üzerinden BNB/USDT için canlı piyasa verileri gösterir.

**Finansal Hizmetler:** Kişisel ve kurumsal finansal planlama ve piyasa analiz hizmetleri sunar.

**Yapay Zeka Destekli Yatırım Önerileri:** Google Gemini 2.0﻿ API sayesinde kullanıcılara kişiye özel yatırım tavsiyeleri sağlar.

---

## Kullanılan Teknolojiler

**Python 3, Flask:** API ve backend geliştirme için kullanılır.

**Google Gemini 2.0 API﻿:** Yapay zeka destekli yatırım önerileri için.

**yfinance:** Finansal piyasa verilerini almak için.

**HTML5, CSS3, JavaScript:** Web sayfası içeriği, tasarımı ve etkileşimleri için.

**Bootstrap 5:** Responsive ve şık arayüz bileşenleri için.

**Font Awesome:** İkonlar ve sosyal medya bağlantıları için.

---

## Kurulum ve Çalıştırma

1. Projeyi klonla veya indir.
2. Python sanal ortam oluştur ve aktif et
3. Gerekli Python paketlerini yükle
4. Proje kök dizininde `.env` dosyası oluştur ve içerisine API anahtarını ekle
5. Flask uygulamasını başlat
6. Tarayıcıda `http://127.0.0.1:5000` adresine git
